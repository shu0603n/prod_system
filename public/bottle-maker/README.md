# Bottle Maker - URLパラメータ一覧

シャンパンボトルラベルデザイナーは、URLパラメータでUIのテキストや色をカスタマイズできます。

## パラメータ一覧

| パラメータ | 型 | 説明 | デフォルト |
|---|---|---|---|
| `color` | 文字列（カラーコード） | タイトル・ボタン等の緑部分の色 | `#2e5b45` |
| `title` | 文字列 | 3Dプレビューエリアの見出しテキスト | `完成イメージ` |

## 使い方

### `color` — アクセントカラーの変更

`#` あり・なし、どちらでも指定できます。

以下の要素の色がすべて変わります：
- 見出し（「完成イメージ」「ラベル画像をアップロード」など）
- ファイル選択ボタン
- 選択中のカラーサークルのボーダー
- 「画像を保存」「リセット」ボタン

```
/bottle-maker?color=2e5b45        # # なし
/bottle-maker?color=%232e5b45     # # あり（URLエンコード）
```

**例:**

```
/bottle-maker?color=c8a415        # ゴールド
/bottle-maker?color=c0392b        # レッド
/bottle-maker?color=2980b9        # ブルー
/bottle-maker?color=8e44ad        # パープル
```

---

### `title` — プレビューエリアの見出し変更

3Dプレビューエリア上部の「完成イメージ」テキストを変更します。  
日本語を含む場合はURLエンコードしてください。

```
/bottle-maker?title=Preview
/bottle-maker?title=%E5%AE%8C%E6%88%90%E3%83%97%E3%83%AC%E3%83%93%E3%83%A5%E3%83%BC   # 完成プレビュー
```

---

## 複数パラメータの組み合わせ

`&` でつなげて複数のパラメータを同時に指定できます。

```
/bottle-maker?color=c8a415&title=Preview
/bottle-maker?color=2980b9&title=%E5%AE%8C%E6%88%90%E3%83%97%E3%83%AC%E3%83%93%E3%83%A5%E3%83%BC
```

## 注意事項

- `color` に指定する値は **16進数カラーコード**（例: `ff0000`）です。色名（`red` など）には対応していません。
- パラメータを省略した場合はデフォルト値が使われます。
- タイトルタグ（ブラウザのタブ名）は常に「オリジナルシャンパンラベルデザイナー」で固定です。
